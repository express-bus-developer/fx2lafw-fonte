# fx2lafw-fonte

Cópia do código-fonte do **sigrok-firmware-fx2lafw**, o firmware de código aberto do projeto
[sigrok](https://sigrok.org/wiki/Fx2lafw) que roda no microcontrolador Cypress FX2 dos
analisadores lógicos.

O agente do Analisador de Redes Automotivas leva este firmware embutido e o carrega no FX2.
O firmware é um programa separado, licenciado sob a **GNU General Public License, versão 2 ou
posterior (GPL-2.0-or-later)**. Este repositório existe para garantir que o código-fonte
correspondente à versão que distribuímos fique sempre disponível, conforme a GPL.
